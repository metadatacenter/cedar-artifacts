# CEDAR Artifacts — DEPRECATED

> [!WARNING]
> This standalone frontend was deprecated on 2026-08-20 and is no longer a
> supported CEDAR application. Do not add new dependencies on this repository.

Metadata-entry forms are now provided by the CEDAR Embeddable Editor within the
maintained CEDAR frontends. Artifact viewing is provided by CEDAR OpenView.

The repository remains temporarily unarchived only while its last integrations
in `cedar-workspace` and `cedar-template-designer` are retired separately. Once
those integrations are removed, this repository will be tagged at its final
state and archived read-only.

Historical source and build instructions remain below their original paths for
reference only.
